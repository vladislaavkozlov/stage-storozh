# Сторож прода Wellstage

Раз в минуту проверяет `https://app.wellstage.ru/health` и онлайн-запись заведений (страница, её скрипт, данные заведения, специалисты). Список заведений - `ZAVEDENIYA` в `storozh.mjs`.

Что приходит в Telegram:
- 🔴 / 🟠 - прод или запись заведения не работают две минуты подряд (сервер ответил ошибкой или не открылся и из России), с подсказкой, куда смотреть. Если проверить из России не удалось - после трёх минут подряд. Про запись - только когда сам прод отвечает
- напоминание раз в 30 минут, пока не работает, и ✅ после двух удачных проверок подряд - с длительностью простоя
- ⚪️ - сам сторож не работал дольше 10 минут (сбой GitHub) и прод в это время не проверялся
- 📊 сводка за прошедшие сутки после 9:00 МСК: простои, доступность, скорость ответа, перезапуски сервера, число коротких обрывов связи. Нет сводки к 10 утра - сторож не работает

Вторая точка в России: сторож живёт на GitHub в США, и связь до Москвы рвётся сама по себе. Когда до сервера не достучались вовсе, сторож просит check-host.net (бесплатно, без ключа) открыть тот же адрес с узлов в Москве и Петербурге. Открылся хоть с одного - тревога ложная, сигнала нет, она считается и приходит числом в сводке.

Работает на GitHub Actions, вне Amvera. Ключ бота и чат - в секретах репозитория `TG_TOKEN` и `TG_CHAT_ID`.

Проверить вручную: вкладка Actions → storozh-proda → Run workflow с галочкой «проверка» - придёт состояние сейчас и счётчики за сегодня.
