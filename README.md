# Сторож прода Stage

Раз в минуту проверяет `https://app.wellstage.ru/health` и онлайн-запись заведений (страница, её скрипт, данные заведения, специалисты) и пишет в Telegram, если что-то не отвечает три раза подряд. Про запись пишет, только когда сам прод отвечает: если лежит весь прод, приходит одно сообщение про прод. Список заведений - `ZAVEDENIYA` в `storozh.mjs`. Пока лежит - напоминает раз в 30 минут, когда ожил - сообщает.

Работает на GitHub Actions, вне Amvera. Ключ бота и чат - в секретах репозитория `TG_TOKEN` и `TG_CHAT_ID`.

Проверить вручную: вкладка Actions → storozh-proda → Run workflow.
